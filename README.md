#  CasioDestop - Version 1 (MVP)

**CasioDestop** est une application web de calculatrice moderne, conçue pour offrir une alternative fluide, élégante et rapide aux calculatrices classiques de bureau.

Ce projet est développé de manière progressive, dans le cadre d'un apprentissage et d'une structuration rigoureuse du code (de la version basique jusqu'à l'application scientifique et de bureau complète).



##  Fonctionnalités de la Version 1 (MVP)
* **Opérations arithmétiques de base :** Addition (`+`), Soustraction (`-`), Multiplication (`*`), Division (`/`).
* **Gestion des décimales :** Calculs précis avec les nombres à virgule.
* **Effacement :** 
  * Touche `C` (Clear) pour tout réinitialiser.
  * Touche `DEL` (Delete) pour supprimer le dernier chiffre ou opérateur saisi.
* **Interface soignée :** Design inspiré des environnements sombres et épurés, optimisé pour une lecture claire des expressions et des résultats.



## Technologies Utilisées
* **HTML5 :** Structure sémantique de la calculatrice.
* **CSS3  :** Mise en page de la grille des touches et design en mode sombre (Dark Mode).
* **JavaScript  :** Logique de calcul, gestion des écouteurs d'événements et mise à jour dynamique de l'affichage.
